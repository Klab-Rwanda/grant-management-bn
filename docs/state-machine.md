# Tranche Lifecycle State Machine (`Grant Ledger`)

> **State Model:** Each tranche tracks **availability** (`availability_status`: `LOCKED` | `ACTIVE` | `CLOSED`) and **review workflow** (`review_status`: `NOT_STARTED` | `DRAFT` | `SUBMITTED_PENDING_REVIEW` | `CHANGES_REQUESTED` | `VERIFIED_PENDING_APPROVAL` | `APPROVED_FOR_DISBURSEMENT` | `DISBURSED_AND_RECONCILED`) as **two separate state fields**. Transitions marked `[OPEN DECISION]` depend on unresolved items in `docs/decisions.md`.

| State (`availability_status` \| `review_status`)                                                                                                                   | Event                                                                           | Who may trigger                                                                                            | Guard conditions                                                                                                                                                                                                                                                                                                                              | Next state (`availability_status` \| `review_status`) | Audit action                          |

| `LOCKED` \| `NOT_STARTED`                                                                                                                                          | `ACTIVATE_INITIAL_TRANCHE`                                                      | `PM` (or System on grant execution)                                                                        | `Grant` is active/signed; `tranche.sequence_order == 1`; no prior tranche prerequisites.                                                                                                                                                                                                                                                      | `ACTIVE` \| `DRAFT`                                   | `TRANCHE_UNLOCKED`                    |
| `LOCKED` \| `NOT_STARTED`                                                                                                                                          | `UNLOCK_NEXT_TRANCHE`                                                           | System (on prior tranche reconciliation or milestone verification)                                         | Prerequisite Tranche `N-1` is `CLOSED \| DISBURSED_AND_RECONCILED` AND all configured `TrancheUnlockConditions` (including required `Milestone` verifications) are satisfied.                                                                                                                                                                 | `ACTIVE` \| `DRAFT`                                   | `TRANCHE_UNLOCKED`                    |
